# Runonmate

One continuous run-on notebook on an A4-width page that never ends. Type, hand-write, draw or add images. Every entry gets a timestamp and tags automatically.

## Use it
- **Quickest:** open `index.html` in Chrome. Nothing to install. Notes are saved on the device.
- **As an installed app (works offline):** host this folder (e.g. GitHub Pages), open it in Chrome, then menu → *Install app* / *Add to home screen*.
  `sw.js`, `manifest.webmanifest` and the icons are only needed for this.

## Privacy
Notes stay on the device (IndexedDB). They only leave it if you turn on cloud AI in Settings and add your own Anthropic API key.
